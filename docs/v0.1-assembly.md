# V0.1 Assembly Plan

This plan is intentionally designed for a builder without machining skills.

## Phase 1 — order

1. Order the 4040 aluminium profiles cut to length from Motedis.
2. Order connector plates, T-nuts and screws with the profiles.
3. Order linear rails only after selecting one rail family and confirming mounting-hole spacing.
4. Order stepper motors, GT2 belts and pulleys.
5. Order electronics and make a small Hall-sensor test fixture first.
6. Print the carriage and one magnetic piece base on the Bambu printer.

## Phase 2 — frame

1. Lay the four 480 mm profiles on a flat table.
2. Join them into a 480×480 mm square using connector plates.
3. Check diagonals before tightening.
4. Add the four 400 mm supports.
5. Add rubber feet.
6. Do not permanently mount the board surface yet.

## Phase 3 — sensing

1. Validate one Hall sensor with one magnetic chess piece.
2. Validate four sensors with four neighbouring pieces.
3. Confirm that a piece on one square does not trigger its neighbours.
4. Only then install the 64-sensor PCB.

## Phase 4 — motion system

1. Install the selected linear rails using their manufacturer dimensions.
2. Install the two CoreXY motors on printed motor mounts.
3. Route the two GT2 belts.
4. Install the 70 mm carriage.
5. Install the electromagnet.
6. Verify free movement manually with power removed.
7. Home the carriage at low speed.

## Phase 5 — electronics

```text
                 Raspberry Pi 5
                       │
                 USB / Ethernet
                       │
                    ESP32-S3
                 ┌─────┼─────┐
                 │     │     │
              Hall   TMC   TMC
              PCB   2209   2209
                 │     │     │
              64 sq  X/Y   X/Y
                       │
                 electromagnet
```

Keep motor and magnet power physically separated from the Hall-sensor wiring as much as practical.

## Phase 6 — calibration

1. Establish machine origin.
2. Measure X/Y square-centre positions.
3. Calibrate 50.00 mm pitch in software.
4. Test all 64 Hall sensors.
5. Test piece pickup/drop at every corner and centre square.
6. Test captures.
7. Test a complete human-vs-AI game.

## Definition of done

A V0.1 build is successful when it can:

- detect a human move on all 64 squares;
- move an opponent piece from any square to any legal destination;
- reliably pick up and release the magnetic piece;
- execute captures into a defined graveyard area;
- recover from a reset without losing board state;
- run a complete Stockfish game without manual intervention.
