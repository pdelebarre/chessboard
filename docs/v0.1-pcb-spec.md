# V0.1 Sensor PCB Specification

## Objective

Create a single under-board PCB that provides one Hall-effect sensing point per chess square and a clean interface to the ESP32 controller.

## Geometry

- Nominal board area: 400 × 400 mm
- 8 × 8 sensing matrix
- Sensor pitch: 50 mm
- Sensor position: square centre
- PCB thickness: target 1.6 mm
- Prefer 2-layer PCB for V0.1

## Recommended architecture

```text
64 × digital Hall sensors
        │
        ├── grouped into 8 × 8 channels
        │
        ▼
address / multiplexing logic
        │
        ▼
ESP32-S3
        │
        ├── USB/serial to Raspberry Pi
        ├── stepper driver 1
        ├── stepper driver 2
        └── electromagnet MOSFET
```

### Design principles

1. Keep every Hall sensor at the geometric centre of its 50 mm square.
2. Use 3.3 V logic throughout the sensor interface.
3. Add local 100 nF decoupling close to each sensor group.
4. Provide a bulk capacitor near the ESP32 power input.
5. Separate stepper/electromagnet current paths from the Hall-sensor ground return as much as practical.
6. Add test points for 3V3, GND, sensor supply and at least one sensor output.
7. Use locking connectors for the Pi/ESP32 and power connections.
8. Add mounting holes outside the 400×400 sensing area.

## V0.1 deliverables for PCB manufacturer

- KiCad schematic
- KiCad PCB layout
- Gerbers
- drill files
- BOM
- pick-and-place file if assembled
- assembly drawing
- functional test procedure

## Manufacturer

SST Hardware is the preferred Dutch supplier for the prototype because it supports PCB production from single prototypes to series, SMT/THT assembly, component sourcing and functional testing in-house in the Netherlands.

## Critical validation

Before ordering the full 400×400 mm PCB, validate the Hall sensor, magnet geometry and sensing distance using a small 8×8 or 4×4 test coupon. This avoids committing to a large PCB before confirming reliable detection with the selected chess-piece magnets.
